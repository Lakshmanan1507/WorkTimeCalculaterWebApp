# Work-calculater-WebApp
A responsive Login Hours Calculator built using HTML, CSS, and JavaScript. It helps users calculate their remaining working hours and estimated logout time based on their completed working hours and login time. Features a modern UI with floating 3D effects, glassmorphism design, and a real-time countdown.


# Login Hours Calculator ⏰

A simple and interactive web application that helps users track their daily working hours and calculate their expected logout time.

## Features
- Enter completed working hours and minutes.
- Set your login time.
- Calculate the remaining working hours.
- Get your estimated logout time.
- View a real-time countdown.
- Modern UI with floating 3D effects and glassmorphism design.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Use
1. Enter your completed working hours.
2. Enter your login time.
3. Set your daily working-hour target.
4. Click the Calculate button to see your expected logout time.

## Purpose
This project was created to make daily work-hour tracking easier and help employees manage their working schedules efficiently.
